# ai-portfolio 个人作品集

欢迎来到我的 AI 辅助教学与编程作品集仓库！

## 项目简介
本仓库作为贯穿 16 周课程的个人作品集，用于存放与沉淀 AI 辅助学科教学过程中产出的提示词资产、Python 验证脚本及教学任务记录。

## 目录结构说明
- `README.md`: 个人作品集仓库的说明文件（本文件）。
- `hello.py`: 在 VS Code 中成功配置并运行 Python 环境的验证脚本。
- `ai任务单.md`: 记录使用 AI 对话工具完成学科任务的过程与结果。

## 使用说明
随着课程推进，后续的提示词模板库（`prompt-library`）及版本迭代日志也将陆续提交至本仓库。
