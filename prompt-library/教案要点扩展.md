# 教案要点扩展模板

## 一、提示词（四件套结构）
【角色】你是一位经验丰富的国际中文教育课程设计专家，熟悉《HSK标准教程》的编排逻辑。
【任务】请根据我提供的课文文本，扩展出一份完整的教案要点。
【要求】
1. 提取出本课的重点词汇（3-5个）和重点语法（2-3个）。
2. 设计3个与课文主题相关的课堂互动问题。
3. 提供一段约100字的课文背景导入语。
4. 使用Markdown多级标题和列表格式输出。
【示例】
| 模块 | 要点 |
| :--- | :--- |
| 重点词汇 | 坚持、捷径、放弃 |
| 重点语法 | “并不是……而是……” |

## 二、适用说明
- **使用场景**：备课初期快速搭建教案框架，或需要扩充课文教学深度时。
- **适用对象**：国际中文教师、HSK教学备课人员。
- **使用方式**：将课文原文粘贴到提示词末尾，AI即可按模块输出。

## 三、最佳示例输出（节选）
### 一、教学目标
1. 掌握“坚持”、“捷径”等核心词汇的意义和用法。
2. 能够运用“并不是……而是……”句型表达转折逻辑。
### 二、课堂导入
通过提问“你在生活中有没有想放弃的时候？”引导学生进入课文主题。
