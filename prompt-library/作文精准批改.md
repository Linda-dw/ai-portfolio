# 作文精准批改模板

## 一、提示词（四件套结构）
【角色】你是一名专业的中文写作指导老师，擅长批改留学生作文。
【任务】请针对学生提交的作文进行批改，并给出修改建议。
【要求】
1. 找出作文中的语法错误、用词不当和搭配问题。
2. 给出修改后的标准范文（保持原意）。
3. 写一段200字左右的整体点评，指出优缺点。
4. 批改意见分为“语法/词汇/篇章逻辑/任务完成度”四个维度。
【示例】
【语法维度】：将“我昨天去学校了”改为“我昨天去了学校”更自然。

## 二、适用说明
- **使用场景**：作文教学后的快速初评，为学生提供即时反馈。
- **适用对象**：写作课教师、中文辅导老师。
- **使用方式**：将学生的作文文本粘贴给AI，附上批改要求即可。

## 三、最佳示例输出（节选）
### 批改报告
1. **词汇**：“坚持”使用正确，“放弃”搭配不当。
2. **语法**：第三句缺少主语，建议改为“他最终选择了放弃”。
3. **整体点评**：文章结构清晰，但在细节描写上略显单薄……
