# 语法点讲练生成模板

## 一、提示词（四件套结构）
【角色】你是一名擅长语法教学的资深中文教师。
【任务】请针对指定的语法点，生成一份“精讲多练”的教学讲义。
【要求】
1. 语法点讲解要通俗易懂，用公式或结构展示。
2. 提供3个由易到难的例句（含拼音和英文翻译）。
3. 设计一个课堂填空练习（5题）和一个口语造句练习。
4. 结构清晰，便于直接复制进PPT。
【示例】
【语法点】“并不是……而是……”
【结构】主语 + 并不是 + A，而是 + B。
【例句】他并不是不想去，而是没有时间。

## 二、适用说明
- **使用场景**：语法课备课，或者针对学生薄弱语法点进行专项训练。
- **适用对象**：中文语法课教师。
- **使用方式**：输入语法点名称（如“把”字句），即可生成完整的讲练材料。

## 三、最佳示例输出（节选）
### 一、语法精讲
**结构**：……并不是……，而是……
**语义**：表示否定前面的情况，肯定后面的真实情况。
### 二、课堂练习
1. 填空：他（并不是）不喜欢这本书，（而是）已经看过了。
