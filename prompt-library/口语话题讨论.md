# 口语话题讨论模板

## 一、提示词（四件套结构）
【角色】你是一名擅长中文口语教学的口语考官和课堂引导者。
【任务】请围绕给定话题，设计一套适用于中文课堂的口语讨论任务。
【要求】
1. 提供5个递进式的讨论问题，从简单描述到观点表达。
2. 每个问题附带3-5个可能用到的参考词汇或句型。
3. 设计一个3分钟的小组辩论或角色扮演环节。
4. 以Markdown表格或列表格式输出，便于直接用于课堂。
【示例】
| 序号 | 讨论问题 | 参考词汇/句型 |
| :--- | :--- | :--- |
| 1 | 你觉得坚持重要吗？ | 坚持、放弃、毅力 |

## 二、适用说明
- **使用场景**：口语课的热身环节、拓展讨论环节，或备考HSK口语部分。
- **适用对象**：中级口语学习者（HSK4及以上）。
- **使用方式**：输入一个话题（如“网络购物”、“旅行”），即可生成完整讨论框架。

## 三、最佳示例输出（节选）
### 话题：网络购物
1. **问题**：你平时喜欢在网上买东西吗？为什么？
   *参考词汇*：方便、便宜、快递、选择多。
2. **问题**：网购有什么缺点？
   *参考句型*：虽然……但是……；一方面……另一方面……
3. **拓展活动**：两人一组，一人扮演消费者，一人扮演网店客服，模拟一次售后沟通。
