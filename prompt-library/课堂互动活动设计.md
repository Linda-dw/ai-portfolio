# 课堂互动活动设计模板

## 一、提示词（四件套结构）
【角色】你是一名活跃的中文课堂活动策划师。
【任务】请根据以下课文主题，设计3个适合中文课堂的互动活动。
【要求】
1. 活动时长分别为5分钟、10分钟、15分钟。
2. 每个活动需包含：活动名称、活动目标、具体步骤、分组方式。
3. 活动要有趣味性，能调动全班参与。
4. 以Markdown格式清晰列出。
【示例】
| 活动名称 | 时长 | 分组 | 步骤 |
| :--- | :--- | :--- | :--- |
| 观点辩论赛 | 15分钟 | 4人一组 | 分正反方辩论课文观点 |

## 二、适用说明
- **使用场景**：课堂气氛沉闷时，或需要开展拓展训练时使用。
- **适用对象**：各类中文课堂教师。
- **使用方式**：提供课文主题或知识点，AI会自动生成对应的活动方案。

## 三、最佳示例输出（节选）
### 活动一：情境模拟（5分钟）
- **目标**：练习本课重点句型。
- **步骤**：同桌两人一组，一人扮演记者，一人扮演课文主角，进行采访对话。
